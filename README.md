# StatMech2025
Repository for 2025 Stat Mech Project

## Installation
1. Open GitHub Desktop
2. Current repository > Add > Clone repository... > GitHub.com > ZachStichter/StatMech2025 > Clone
3. Ctrl+Shift+A to open in VS Code
4. Ctrl+\` to open the terminal
5. Type \`\<python command> -m pip install requirements.txt

## Contributing
1. Open GitHub Desktop
2. Fetch origin
3. Select changed files
4. Type short commit message
5. Commit to main
